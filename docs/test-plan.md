# 测试计划与结果

## 1. 策略
| 层级 | 工具 | 对象 | 命令 |
|---|---|---|---|
| 单元测试 | Vitest | 战斗引擎、成长、存档 | `npm test` |
| 数据测试 | Vitest + Ajv | 全部 JSON 内容符合 Schema、引用完整 | 同上 |
| 平衡模拟 | Vitest + 自动玩家（`tests/sim.ts`） | 通关曲线是否合理 | 同上 |
| 类型检查 | `tsc --noEmit`（strict, noUnusedLocals） | 全部源码与测试 | `npm run build` 中包含 |
| 端到端冒烟 | Playwright-core + Chrome 移动端模拟（iPhone 13） | 真实浏览器里的完整流程、存档、PWA | `npm run e2e`（需先 `npm run preview`） |
| 视觉检查 | 截图 | 各界面在手机视口下的布局 | `npm run shots` |

测试方法要点：战斗引擎测试通过**自定义最小技能和固定属性**构造场景（`tests/helpers.ts`），把「暴击」影响排除（暴击率在测试配置中可控/或选取不触发的种子），逐条断言事件日志。
