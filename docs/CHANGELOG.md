## [0.1.0] - 2026-11-01（MVP）

### 新增
- 战斗引擎：速度排序、怒气、绝技、合击、护盾/灼烧/增减益/嘲讽/封绝；种子化随机，事件日志可回放。
- 数据：12 名武将（蜀 6/魏 6）、7 种敌人（含 3 个 Boss）、4 个羁绊（含 1 个合击技「雷霆定策」）、10 个关卡；全部通过 JSON Schema 校验。
- 养成：升级（银两）、进阶（将魂石，最多 3 阶）、首通奖励与武将解锁、星级。
- 存档：`localStorage`，版本号 + 迁移表 + 防御式清洗；坏档备份。
- 界面（DOM + SVG，竖屏）：出征/阵容/武将/羁绊 4 个页签、战斗回放（行动顺序条、血条、怒气点、飘字、横幅、倍速/跳过）、结算弹窗、新手引导、设置。
- PWA：manifest、Service Worker、图标（含 maskable）。
- 测试：44 个 Vitest 用例 + 14 项浏览器 E2E 冒烟。
- 文档：SRS、架构、数据模型、战斗规则、测试计划、开发日志。

### 修复（开发期间）
- 战斗：防御被增益/减益压到 1 以下时错误地取下限 1，导致防御为 0 时伤害偏低（改为防御下限 0，其余属性下限 1）。
- 数据测试：Ajv 重复编译 Schema 报 "schema already exists"（改为按文件名缓存）。
- 战斗界面：小屏（390×664）下后排被日志栏遮挡，改为按视口高度缩放头像并在矮屏隐藏图例。

### 平衡调整
- 升级费用由较高的曲线下调为 `30 + 15×等级`；关卡敌人等级加成调整为 `0,1,2,2,3,4,4,5,3,5`，使第 5/8/9/10 关形成门槛而非「前 9 关无压力、第 10 关断崖」。
