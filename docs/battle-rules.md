# 战斗与成长规则规格

本文是游戏规则的**权威描述**；实现位于 `src/core/battle.ts`（常量 `RULES`）、`progression.ts`、`setup.ts`、`game.ts`，每条规则在 `test-plan.md` 中有对应测试。所有数值与名称均为原创设计。

## 1. 阵位与目标选择
- 每方 6 个阵位：0–2 前排，3–5 后排（阵位号小者更靠前）。
- 目标选择器：

| 选择器 | 规则 |
|---|---|
| `enemy-front` | 敌方存活者中**前排优先**、阵位号小者优先的 1 人。普攻多用此项 |
| `enemy-back` | **后排优先**的 1 人（后排死光才打前排） |
| `enemy-back-2` | 后排优先的 2 人 |
| `enemy-all` | 敌方全体存活者 |
| `enemy-lowest-hp` | 当前生命值最低的敌人 |
| `enemy-top-atk` | 当前攻击最高的敌人 |
| `self` / `ally-all` | 自身 / 我方全体存活者 |
| `ally-lowest-hp` | 生命比例最低的友军 |

- **嘲讽**：被嘲讽者存活时，敌方所有「单体」选择器（front/back/lowest-hp/top-atk）强制改打嘲讽者（范围与群体技能不受影响）。

## 2. 回合与行动顺序
1. 每个**回合（round）**开头，把双方所有存活单位按**当前速度**从高到低排序；速度相同则**我方先于敌方**，再按阵位号。
2. 依次行动；行动前若该单位已死亡则跳过；任何时刻一方全灭，战斗立即结束。
3. 每名单位的**一次行动（turn）**：
   1. 结算身上的**灼烧**（见 §5）；
   2. 若仍存活：若怒气 ≥ 4 且未被封绝 → 消耗 4 点怒气，释放**绝技**（或**合击**，见 §4）；否则**普攻**，普攻结算后自身怒气 +2；
   3. 状态倒计时（增减益、嘲讽、封绝各 −1 回合，到 0 失效）。
4. 超过 **20 回合**仍未分胜负：判我方失败（`timeout`）。

## 3. 怒气
| 事件 | 变化 |
|---|---|
| 战斗开始 | 每名单位 1 点 |
| 普攻后 | 自身 +2 |
| 受到**攻击伤害**（`hit`，灼烧不计） | 受击者 +1（含被护盾完全吸收的攻击；已死亡者不加） |
| 释放绝技/合击 | −4 |
| 技能效果 `rage` | 按 amount 增减 |
| 上限 / 下限 | 8 / 0 |

> 设计意图：普攻越多越快攒满；被集火的单位也会更快放绝技；怒气上限 8 允许「溢出」后连放。

## 4. 合击（羁绊技）
- 羁绊可带一个合击技，指定**发起者**。
- 条件（全部满足才触发）：发起者是**我方**单位；发起者怒气满足绝技条件（≥4 且未被封绝）；该羁绊的**其余所有成员当前都存活**在我方阵上。
- 效果：发起者本次行动释放**合击技代替自身绝技**，同样消耗 4 点怒气。搭档阵亡后退化为发起者的普通绝技。
- 敌方单位不会释放合击。
- 当前唯一合击：**雷霆定策**（曹操发起，郭嘉在场）——对敌方全体造成 170% 攻击的伤害，敌方全体怒气 −2，我方全体怒气 +1。

## 5. 伤害、治疗与状态
**伤害** = 攻击 × 技能倍率 × 100 ÷ (100 + 防御) × 暴击系数，向下取整，至少为 1。
- 攻击、防御取**含增减益后的当前值**；防御下限 0，其余属性下限 1。
- 暴击率 10%，暴击系数 ×1.5；暴击判定使用种子化随机数。
- 多段攻击（`hits`）每段独立判定；单体选择器每段重新选目标。
- 吸血 `lifesteal`：按实际造成的伤害比例回复自身，不超过最大生命。

**治疗** = 施法者攻击 × 倍率，不超过最大生命。
**护盾** = 施法者最大生命 × 倍率，可叠加；伤害先扣护盾再扣生命。
**灼烧**：每次受影响单位行动开始时受到「施加时施法者攻击 × 倍率」的伤害，**无视防御，但会被护盾吸收，且不产生怒气**，持续指定行动次数。
**增益/减益**：属性按百分比叠加（同属性多个效果相加），在**持有者**每次行动结束时递减；若在持有者自己的行动中被施加，则不会在当次行动末立刻递减一次（多给 1 次，保证「持续 N 回合」体验一致）。
**封绝**：持有期间无法释放绝技/合击，只能普攻（怒气继续积累）。
**嘲讽**：见 §1。

## 6. 确定性
战斗随机性只来自暴击判定，使用 `mulberry32(seed)`。相同的 `BattleSetup`（含 seed）必产生相同的事件日志。UI 每次开战随机取一个 seed（`Math.random()`）。

## 7. 属性计算
单个武将进入战斗的四维：
```
statMult = (1 + 0.10 × (等级 − 1)) × (1 + 0.15 × 进阶)
属性 = round(基础 × statMult × (1 + 羁绊加成))      // hp / atk / def
速度 = round(基础速度 × (1 + 羁绊速度加成))         // 速度不随等级/进阶成长
```
- 同时激活的多个羁绊，同一属性的加成**相加**后再乘。
- 敌人：`属性 = round(基础 × (1 + 0.10 × (关卡等级 − 1)))`，速度不变；无进阶、无羁绊。
- 战力 = round(生命/10 + 攻击×1.5 + 防御×1.2 + 速度×0.5)，仅用于显示与建议。

## 8. 养成
| 项 | 规则 |
|---|---|
| 等级上限 | `10 + 5 × 进阶`（0 阶 10 级 … 3 阶 25 级） |
| 升级费用（银两） | `30 + 15 × 当前等级` |
| 进阶条件 | 当前已满级且未满 3 阶 |
| 进阶费用（将魂石） | `2 × (当前阶 + 1)`：2、4、6 |
| 初始资源 | 银两 300、将魂石 0 |

## 9. 关卡与奖励
- 关卡逐关解锁：通关第 N 关才能挑战第 N+1 关。
- 通关奖励：`gold` + `stones`；**首次**通关额外 `firstClearGold`，并解锁 `unlockGeneral`（若有）。
- 星级：我方全员存活 3 星；阵亡 1 人 2 星；阵亡 ≥2 人 1 星；失败 0 星。进度只记录历史最高星级。
- 失败不扣资源，可无限重试。

## 10. 与参考品类的差异说明
本作采用「前后排站位、自动战斗、怒气满放绝技、羁绊」这类品类通用的机制思路，具体规则（怒气数值、速度排序规则、合击触发条件、成长公式、技能与数值）均为本项目自行设计，并不声称与任何现有游戏一致。
